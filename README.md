##   Общая информация

###   Условия сотрудничества

* ◆ Предоплата: 50% от стоимости выбранного пакета.
* ◆ Сроки: Поэтапное оформление, полный дизайн – за 1 месяц.
* ◆ Оплата: Через гаранта или 100% предоплата (без посредников).
