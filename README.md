## Общая информация
Данная смета включает стоимость разработки полного дизайн-проекта для магазина, "под ключ", включая разработку фирменного стиля, дизайн-макетов для различных носителей и оформление онлайн-платформ. Предоставлены три варианта пакетов услуг: "Старт", "Оптима" и "Премиум", различающихся по объему и детализации работ.

- **Предоплата:** 50% от общей стоимости выбранного пакета.
