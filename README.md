#  ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎ 📜 Описание

> *ТУР 🤖 Рейтинг + рулетка* - это ваш незаменимый Telegram-бот для организации игр и честных розыгрышей в чате!
> Он с легкостью позволяет отслеживать активность участников, начислять им баллы за меткие ответы и отображать их успехи в наглядной таблице лидеров.
> А когда придет время награждать лучших, бот проведет случайный розыгрыш с возможностью исключения участников, что идеально подходит для определения нескольких победителей в серии! Бот также умеет отслеживать активных игроков и призывать их по команде.

## ┏━━━━━ 🛠️ Основные команды: ━━━━┓ 

✨ **Общие команды и справка:**
* `.ррхелп` (или `/rrhelp`): Показывает это сообщение с описанием всех возможностей бота.
* `.рртаб`: 🏆 Показывает актуальный рейтинг участников с их количеством баллов и списком последних ответов.

✍️ **Управление ответами:**
* `.рр` (в ответ на сообщение): ✅ Добавить балл! Ответьте этой командой на сообщение участника, чтобы добавить его ответ в рейтинг. После 3-х ответов пользователь попадает в список активистов.
* `.мрр <номер>`: ❌ Удалить ответ! Удаляет указанный ответ из рейтинга и списка розыгрыша. Номера последующих ответов автоматически пересчитываются.

🎮 **Призыв игроков:**
* `.рригра`: 📣 Зовите на следующую игру активных игроков (кто дал >= 3 ответа)! Отправляет сообщение с упоминанием всех активистов.

🎲 **Розыгрыш:**
* `.рруля`: 🎉 Время рулетки! Запускает случайный выбор победителя среди всех ответов в пуле и объявляет счастливчика. Выигравший ответ удаляется из пула.
* `.мрруля @<логин>`: 🚫 Исключить из рулетки! Удаляет все ответы указанного пользователя из пула розыгрыша.
* `.ррпул`: 📊 Показать пул! Отображает список пользователей, чьи ответы участвуют в текущем розыгрыше, с указанием номеров их ответов.

⚠️ **Сброс:**
* `.рратио`: 🗑️ Сбросить всё! Полностью очищает все данные бота для **текущего чата**. _(Только для администраторов)_

🔑 **Администрирование:**
* `/rradm <user_id>`: ➕ Добавить админа! Добавляет пользователя с указанным ID в вайтлист. _(Только для администраторов)_
* `/mrradm <user_id>`: ➖ Удалить админа! Удаляет пользователя с указанным ID из вайтлиста. Владельца бота удалить нельзя. _(Только для администраторов)_

## ┗━┉┉┻ 🕹️ Инструкция использования: ┉┓

1.  `.ррхелп`: Ознакомьтесь с командами.
2.  Добавляйте правильные ответы участников в таблицу.
3.  Удаляйте ошибочные ответы при необходимости.
4.  Следите за рейтингом.
5.  Проверяйте, кто участвует в розыгрыше.
6.  Проводите розыгрыш!
7.  Убирайте победителя розыгрыша из прокрута, если нужно определить более одного победителя.
8.  Призывайте активных игроков на новую игру командой `.рригра` в чате.
9.  Очищайте все данные перед началом совершенно новой сессии (если требуется).

## ┗━━━━━━━━ ⚙️ Принцип работы:

###  💾 *Хранение данных:*
   
*   **Рейтинг и ответы:** Для каждого чата создается отдельный файл состояния на **Google Drive**. Это гарантирует, что данные не потеряются при перезапуске бота и что рейтинги разных чатов не смешиваются. 
    *  **Добавление ответа (`.рр`):** Бот загружает состояние чата с Google Drive, добавляет ответ, увеличивает счетчик пользователя, проверяет, достиг ли пользователь порога в 3 ответа (и если да, добавляет его в локальный файл актива), а затем сохраняет обновленное состояние обратно на Google Drive.
    *   **Удаление ответа (`.мрр`):** Бот загружает состояние, удаляет указанный ответ, пересчитывает номера всех последующих ответов, обновляет пул для розыгрыша (также сдвигая номера) и сохраняет изменения на Google Drive.
*   **Активные игроки:** Список пользователей, давших 3 или более ответа, хранится в локальном файле `active_players.json` в папке с ботом. Этот файл используется для команды `.рригра`.
*   **Администраторы:** Список ID администраторов хранится в локальном файле.

###   🎱 *Розыгрыш* (`.рруля`):
    1.  Бот загружает актуальное состояние чата 💻
    2.  Используется криптографически стойкий генератор случайных чисел Python (`secrets.choice`) для выбора случайного *номера ответа* из текущего пула (`roll_pool`). Модуль `secrets` использует источники энтропии операционной системы, что делает выбор непредсказуемым и подходящим для задач, где важна безопасность и честность 🔒
    3.  Выбранный номер удаляется из пула ❌
    4.  Бот находит пользователя, которому принадлежит этот номер ответа 🙋🏻‍♂️
    5.  Объявляется победитель 🏆 
    6.  Обновленное состояние (с уменьшенным пулом) сохраняется на Google Drive 💿

*   **Призыв (`.рригра`):** Бот читает локальный файл `active_players.json` и формирует сообщение с упоминаниями всех пользователей из этого списка 📢

*   **Транзакции:** Большинство операций, изменяющих состояние (добавление/удаление ответа, розыгрыш, очистка), обернуты в транзакционный механизм. Если во время выполнения команды или при последующем сохранении на Google Drive происходит ошибка, все изменения, сделанные в памяти во время этой команды, откатываются, чтобы предотвратить несогласованность данных 🚥
